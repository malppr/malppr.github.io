## Overview

BeetleBot was my final-year capstone, built with NCS. The goal was an autonomous robot that replaces full refuse bins, aimed at airport environments. We built a full-scale prototype on an NCS mobile robot base, with a forklift-like mechanism that picks up bins and carries them to a central collection point.

## How it works

The robot runs a bin-handling pipeline in ROS: **locate** the bin, **navigate** to it, **align**, **lift** and **transport** it. Combined with the mobile base's navigation stack, this gives a fully automated bin swap. In testing, it successfully swapped the bin in every run.

Around the robot, we also built a mobile app, a web dashboard and a back-end server that schedules a potential swarm of robots, so operators can monitor and control the whole system.

## What I did

As lead for the robotic unit, I designed the frame, built the bin-handling pipeline, and oversaw the integration of software and electronics so the hardware worked reliably end to end.
