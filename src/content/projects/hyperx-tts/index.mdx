## Overview

Every language has its own phonetic system and prosody, which makes it hard to build one text-to-speech (TTS) model that works well across many languages. Fine-tuning the whole model for each new language is expensive.

This project brings **parameter-efficient transfer learning** (PETL) into TTS. Instead of updating the whole model, we insert small **adapters** into a SpeechT5 backbone, and use a **hypernetwork** to generate the adapter parameters conditioned on the speaker, the language and the layer. This matched full fine-tuning while training only about 2.5% of the parameters.

## What I did

- Modified the model to accept new phonemes from different languages (multilingual tokenizer adaptation).
- Built the data-processing pipeline for the CSS10 dataset and fine-tuned the model on several languages.

The paper is available on [arXiv](https://arxiv.org/abs/2406.17257).
